# Web App Integration Guide\n\n## Overview\nThis landing page is designed to promote the Xpense web application hosted at `app.xpense.web.id`. The landing page is a separate marketing site (xpense-website) that directs users to the actual app.\n\n## Architecture\n\n```\n┌─────────────────────────────────┐\n│   xpense-website (This Repo)    │\n│   Marketing Landing Page        │\n│   • Hero section with CTA       │\n│   • Feature showcase            │\n│   • Benefits & use cases        │\n│   • Links to app at:            │\n│     app.xpense.web.id           │\n└────────────┬────────────────────┘\n             │\n             │ External Link\n             ▼\n┌─────────────────────────────────┐\n│   Xpense Web App                │\n│   https://app.xpense.web.id     │\n│   • Multiple projects           │\n│   • Wallets & categories        │\n│   • Offline support (PWA)       │\n└─────────────────────────────────┘\n```\n\n## Key Integration Points\n\n### 1. Hero Section CTA\n- **Button Text**: \"Launch App\"\n- **URL**: `https://app.xpense.web.id`\n- **Behavior**: Opens in new tab\n- **Location**: Hero section top-right\n\n### 2. Main CTA Section\n- **Button Text**: \"Start Using Xpense\" (with 🚀 emoji)\n- **URL**: `https://app.xpense.web.id`\n- **Behavior**: Opens in new tab\n- **Location**: Bottom of page (before footer)\n\n### 3. Benefits Section\n- **Subtitle**: Emphasizes \"Access Anywhere, Anytime\"\n- **Key Message**: \"Just visit app.xpense.web.id to get started\"\n- **Benefits Listed**:\n  - 🌐 Web-Based: Access from any browser, no installation needed\n  - 📱 Responsive Design: Perfect experience on mobile, tablet, or desktop\n  - ⚡ Instant Access: No app store needed, works with just a web link\n\n### 4. Hero Copy\n- **Mention**: URL is featured in the main value proposition\n- **Text**: \"Access it instantly at app.xpense.web.id\"\n\n## Implementation Details\n\n### Link Configuration\nAll external links to the app use:\n```svelte\n<a\n  href=\"https://app.xpense.web.id\"\n  target=\"_blank\"\n  rel=\"noopener noreferrer\"\n  class=\"...button-classes...\"\n>\n  Button Text\n</a>\n```\n\n### Why `target=\"_blank\"`?\n- User stays on landing page after clicking\n- Can review more information before committing to app\n- Allows easy return to landing page\n- Professional user experience\n\n### Why `rel=\"noopener noreferrer\"`?\n- **Security**: Prevents the web app from accessing the `window.opener` object\n- **Privacy**: Prevents referrer information leakage\n- **Best Practice**: Standard for external links\n\n## Deployment Considerations\n\n### Landing Page URL\n- This landing page should be hosted at the root domain or subdomain\n- Example: `xpense.web.id` or `www.xpense.web.id`\n\n### App URL\n- The actual Xpense app is at: `app.xpense.web.id`\n- This is a separate subdomain pointing to the app deployment\n\n### DNS Configuration Example\n```\nxpense.web.id          → Landing page (this repo)\napp.xpense.web.id      → Web app deployment\nwww.xpense.web.id      → Redirect to xpense.web.id (optional)\n```\n\n## Analytics Integration\n\nConsider adding tracking to:\n1. **\"Launch App\" clicks** -
